/bin is a symbolic link (shortcut) to /usr/bin. It is kept so that old
programs and scripts that still expect /bin continue to work.
/usr/bin is where most of the system commands installed by Ubuntu live,
such as ls, git, and python3. /usr/local/bin is reserved for programs
that I install myself by hand, so they are kept separate from Ubuntu's
own programs and do not get overwritten during system updates.
